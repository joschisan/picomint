Install guide

Run a Picomint Node,
one command at a time.

For someone who has never used a terminal. Each step is one line to copy, what it does in plain words, and what the screen looks like when it worked. Every line works from a freshly opened terminal, so there is nothing to navigate. At the end your node runs in the background and you continue in the browser. Every line can be run again without harm, so if something looks wrong, run it once more.

About 15 minutesplus a day or two for Bitcoin to sync in the background
Ubuntu 26.04 desktopfreshly installed, 50 GB of free disk, and you know your login password
Six commandsto install, and one each to read the log and to update
Part 1

Open a terminal

The terminal is a window where you type a line and press Enter to run it. Everything in this guide happens in one such window.

Press Ctrl + Alt + T. A dark window opens with a short line ending in $ and a blinking cursor. That is the terminal waiting for you.

satoshi@desktop: ~
satoshi@desktop:~$

Three things to know before you type anything.

  • Pasting. Ctrl + V does nothing in a terminal. Right-click in the window and choose Paste, or press Ctrl + Shift + V. Then press Enter to run the line.
  • sudo. Lines starting with sudo change the system, so Ubuntu asks for your login password first. Nothing appears while you type it, not even dots. Type it and press Enter. It remembers you for a few minutes, so you will not be asked every time.
  • Done means quiet. A command is finished when the $ line comes back. No news is good news. Errors are printed in words, usually with the word error in them.
Part 2

Install Docker

Docker runs the node and Bitcoin Core in the background and starts them again after a reboot. Ubuntu ships it, so this is one install command.

Paste this line and press Enter. It refreshes Ubuntu's list of available software, then installs Docker and its companion tool Compose. Type your password when asked.

Command
sudo apt update && sudo apt install -y docker.io docker-compose-v2

Expect a minute or two of scrolling text. The last lines look like this.

satoshi@desktop: ~
satoshi@desktop:~$ sudo apt update && sudo apt install -y docker.io docker-compose-v2

Check it worked. This prints Docker's version number. Any number is fine.

Command
sudo docker --version
Part 3

Download the compose file

One small file tells Docker which two programs to run and how. This line fetches it from the Picomint project and puts it where the later commands expect it.

Paste and press Enter. It downloads the file into a folder called picomint in your home folder, creating the folder on the way. Nothing is printed when it works.

Command
curl -fsSL --create-dirs -o ~/picomint/docker-compose.yml https://raw.githubusercontent.com/joschisan/picomint/main/docker-node/docker-compose.yml

Check it is there. This prints the whole file. It should end with the two volumes lines; if it stops earlier, the download broke off and you run the line above again.

Command
cat ~/picomint/docker-compose.yml
satoshi@desktop: ~
satoshi@desktop:~$ curl -fsSL --create-dirs -o ~/picomint/docker-compose.yml https://raw.githubusercontent.com/joschisan/picomint/main/docker-node/docker-compose.yml
satoshi@desktop:~$ cat ~/picomint/docker-compose.yml
# Both services run on the host network. The node's p2p and client api
# share one iroh endpoint (UDP), and stacking Docker's NAT on top of the
# router's would give iroh two layers to punch through instead of one. That
# means each service binds its own address rather than being contained by a
# published port, so the loopback binds below are what keep the Web UI and
# the Bitcoin RPC off the LAN.
services:
  picomint-node-daemon:
    image: ghcr.io/joschisan/picomint-node-daemon:main
    container_name: picomint-node-daemon
    restart: always
    network_mode: host
    logging:
      options:
        max-size: 100m
    depends_on:
      - bitcoind
    volumes:
      - picomint_node_daemon_data:/data
    environment:
      - DATA_DIR=/data
      - BITCOIND_URL=http://bitcoin:bitcoin@127.0.0.1:8332
      # The iroh endpoint must be reachable from the internet for nodes and
      # clients to talk to your node.
      - P2P_ADDR=0.0.0.0:8080
      # Web UI — loopback only, reachable from a browser on this machine and
      # nowhere else. Do not change this to 0.0.0.0: on the host network that
      # puts node administration on your LAN.
      - UI_ADDR=127.0.0.1:3000

  bitcoind:
    image: bitcoin/bitcoin:latest
    container_name: bitcoind
    restart: always
    network_mode: host
    logging:
      options:
        max-size: 100m
    volumes:
      - bitcoind_data:/home/bitcoin/.bitcoin
    command:
      - -server=1
      # RPC is loopback only — the node shares this network namespace, and
      # nothing else needs to reach it.
      - -rpcbind=127.0.0.1
      - -rpcallowip=127.0.0.1
      - -rpcuser=bitcoin
      - -rpcpassword=bitcoin
      - -dbcache=1024
      # Keeps roughly the last 30 days of blocks, which is all the mint needs.
      # Remove this line to run a full node.
      - -prune=20000

volumes:
  picomint_node_daemon_data:
  bitcoind_data:
satoshi@desktop:~$
What is in it. The node itself, the official Bitcoin Core, and the settings that keep the dashboard reachable from this machine only. You never need to open or edit it. If you are curious, it is the same file on GitHub.

Editing the file. You will not normally need to, but it is plain text and one setting in it is worth knowing about. To open it, use nano, a small editor that runs inside the terminal:

Command
nano ~/picomint/docker-compose.yml
Bitcoin is pruned by default. The -prune line near the end keeps roughly the last 30 days of blocks with margin to spare, about 35 GB in all, which is all the mint needs. If you have 1.2 TB to spare and want the whole chain, open the file as above and remove that line before starting the node.
Part 4

Start the node

Two commands. The first downloads the node and Bitcoin Core. The second starts them and keeps them running. Both name the file from Part 3, so they work from any terminal.

Download. About a gigabyte, so this takes a few minutes on a home connection. A progress bar per piece is normal.

Command
sudo docker compose -f ~/picomint/docker-compose.yml pull
satoshi@desktop: ~
satoshi@desktop:~$ sudo docker compose -f ~/picomint/docker-compose.yml pull
[sudo] password for satoshi:
[+] Pulling 14/14
 ✔ bitcoind Pulled                                        41.2s
 ✔ picomint-node-daemon Pulled                            12.8s
satoshi@desktop:~$

Start. The -d at the end means "in the background". The terminal comes back right away and the two programs keep running without it.

Command
sudo docker compose -f ~/picomint/docker-compose.yml up -d
satoshi@desktop: ~
satoshi@desktop:~$ sudo docker compose -f ~/picomint/docker-compose.yml up -d
[+] Running 4/4
 ✔ Volume "picomint_bitcoind_data"              Created
 ✔ Volume "picomint_picomint_node_daemon_data"  Created
 ✔ Container bitcoind                           Started
 ✔ Container picomint-node-daemon               Started
satoshi@desktop:~$

Check they are running. This lists the two programs and their state. Both should say Up.

Command
sudo docker compose -f ~/picomint/docker-compose.yml ps
satoshi@desktop: ~
satoshi@desktop:~$ sudo docker compose -f ~/picomint/docker-compose.yml ps
NAME                   IMAGE                                          STATUS
bitcoind               bitcoin/bitcoin:latest                         Up 40 seconds
picomint-node-daemon   ghcr.io/joschisan/picomint-node-daemon:main    Up 39 seconds
satoshi@desktop:~$
Part 5

Open the dashboard

The terminal work is done. Everything from here on happens in your browser.

Open the dashboard. Open your browser and go to http://127.0.0.1:3000. Bookmark it. The node setup, the mint ceremony with your co-operators and everything after that happens on that page. This guide stops here, apart from the two upkeep commands below.

You can close the terminal now. The node and Bitcoin Core keep running, survive a reboot, and start before you log in. Bitcoin Core spends a day or two downloading the chain; the dashboard's block height shows how far it has got.
Part 6

See what the node is doing

You never have to read the node's log. This is for when a co-operator asks what your node is saying.

Open a terminal and run this. It prints the last 200 lines of the node's log and keeps printing new ones as they happen. Without the --tail it would print everything the node has ever logged first, which is a lot of scrolling for nothing.

Command
sudo docker compose -f ~/picomint/docker-compose.yml logs --tail 200 -f picomint-node-daemon

To stop watching, press Ctrl + C. That stops the log window only. The node is not affected.

Bitcoin Core's log is the same line with its name at the end. While it is still downloading the chain, this is where you see it progress.

Command
sudo docker compose -f ~/picomint/docker-compose.yml logs --tail 200 -f bitcoind
Part 7

Update to a new release

Your co-operators will tell you when there is one. Updating is the two start commands again.

Download the new release. The same line as in Part 4.

Command
sudo docker compose -f ~/picomint/docker-compose.yml pull

Start it. Docker replaces only what changed and leaves your node's data alone.

Command
sudo docker compose -f ~/picomint/docker-compose.yml up -d
satoshi@desktop: ~
satoshi@desktop:~$ sudo docker compose -f ~/picomint/docker-compose.yml pull
[sudo] password for satoshi:
[+] Pulling 6/6
 ✔ picomint-node-daemon Pulled                            14.1s
 ✔ bitcoind Pulled                                         0.9s
satoshi@desktop:~$ sudo docker compose -f ~/picomint/docker-compose.yml up -d
[+] Running 2/2
 ✔ Container bitcoind              Running
 ✔ Container picomint-node-daemon  Started
satoshi@desktop:~$

A program that says Running had no update and was left alone. One that says Started was replaced with the new release. The node restarts by itself and rejoins the mint within a minute.

Rebooting the machine needs no command at all. Ubuntu's own updates may ask for a restart; go ahead. Both programs come back on their own.
