Picomint alpha GitHub

Bitcoin Community Custody

Picomint lets communities create private community banks on Bitcoin called mints.

To run a mint yourself you need at least four people to run a node each. The nodes then connect to each other and form a single replicated mint - individual nodes can fail and the mint continues to operate. Follow the guide to run your own node. Once it runs you can connect to other nodes and monitor the node through a dashboard in your browser.
